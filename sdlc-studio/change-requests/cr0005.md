# CR-0005: Replace placeholder brand icon with Agent Crew logo

> **Status:** Implemented
> **Priority:** P3
> **Type:** design-change
> **Requester:** Darren Benson
> **Date:** 2026-06-09
> **Affects:** brand assets (`custom_components/agent_bridge/icon.png`)
> **Depends on:** —
> **GitHub Issue:** —

## Summary

Swap the integration's placeholder brand icon for the official Agent Crew logo, sized to Home Assistant's brand-image conventions.

## Problem

The integration shipped a 133×133 placeholder `icon.png`. Home Assistant's brand convention expects a square 256×256 `icon.png` (plus an optional 512×512 `icon@2x.png` for hiDPI). The placeholder was undersized and not the project's actual branding, so the integration showed a low-resolution non-brand icon in Settings → Devices & Services.

---

## Proposed Changes

### Item 1: Replace brand icon with Agent Crew logo

**Priority:** P3
**Effort:** XS

Resize the source logo (`agent-crew.png`, 400×400 RGBA square) with Lanczos resampling and install it as the HA brand icon:

- `custom_components/agent_bridge/icon.png` → 256×256 (HA standard brand icon)
- `custom_components/agent_bridge/icon@2x.png` → 512×512 (hiDPI variant, new file)
- `custom_components/agent_bridge/icons/icon.png` + `icons/icon@2x.png` → kept in sync

Source is a clean square, so no cropping was needed.
