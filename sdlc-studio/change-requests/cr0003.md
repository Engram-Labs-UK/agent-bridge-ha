## Summary

Three related improvements to how an operator selects and configures a bridge agent as
a Home Assistant voice entity, surfaced during first live deployment:

1. **Crew-scoped picker.** Discovery exposes a per-agent `crew`. The conversation
   subentry flow now cascades **crew → agent**: pick a crew (or "All crews"), then the
   agent list is filtered to that crew (and to selectable agents only, per BG0003).

2. **HA-origin instructions, editable in the UI.** Agents did not reliably know a turn
   came from Home Assistant: the `x-bridge-mcp-caller: homeassistant` header is used by
   the bridge for crew gating (not folded into the agent prompt), and the request
   `metadata` (source/device/area) is dropped by the http-openai adapter (CR-0002 G12).
   The fix is **prompt-fold** (the chosen OQ6 direction — no bridge change): the entity
   prepends an operator-editable instructions block to the system prompt telling the
   agent the request is from Home Assistant and to actuate via its HA tools. The field
   defaults to `DEFAULT_PROMPT` and is editable per agent at creation and via a
   subentry **reconfigure** step (mirrors the OpenAI conversation integration).

3. **Filter non-agents from every picker** (tracked as BG0003).

## Scope

- `helpers.is_selectable_agent` / `agent_crew`; applied to config-flow, subentry and
  options pickers + the entity-creation gate.
- Cascading crew→agent subentry flow (`async_step_user` crew, `async_step_agent`),
  editable `prompt` field (TextSelector multiline), `async_step_reconfigure`.
- Coordinator `AgentInfo` gains `identity_substrate` + `crew`; `capability_envelope`
  corrected to the object shape.
- System prompt builder folds the instructions layer; entity carries the per-agent prompt.
- Subentry UI strings (crew/agent/instructions/reconfigure).

## Out of Scope

- A bridge metadata-passthrough CR (structured device/area context) — deferred; prose
  prompt-fold is sufficient for now (OQ6).

## Acceptance (verified by tests)

- Models (`identitySubstrate: none`), chatbots, workerbots, orchestrators excluded from
  pickers + entity creation; real persona/engram agents and legacy entries included.
- Crew step lists declared crews + "All crews"; agent step filtered to the chosen crew.
- New subentry stores `prompt` (default `DEFAULT_PROMPT`); reconfigure updates it.
- The entity folds the per-agent instructions into the outbound system message.
