## Summary

The RV0006 release-gate review (before tagging 0.10.0) found the PRD, TRD and TSD significantly stale versus the shipped code. The 0.10.0 release applied **targeted** corrections (marked the removed tool-execution loop / options / event as superseded, added changelog + currency-note banners, added the new features to the PRD inventory at summary level). This CR tracks the **deeper expansion** that was out of scope for the release gate.

## Problem

The three spec docs were last fully reviewed 2026-04-05 and predate EP0007, EP0008, and the CR-0006..CR-0010 pass. The currency notes added in 0.10.0 stop them from actively misleading, but full feature/interface/test documentation is still missing.

### Item 2: TRD interfaces, endpoints, modules, ADR

**Priority:** P3

Add the 4 new client methods + endpoints to §5; add `usage`/`doctor`/`tool_surface`/`read_only_safe` to the §6 CoordinatorData; add `ai_task.py`, `diagnostics.py`, `drift.py`, `webhook.py` to the component table + repo structure; remove `tool_executor.py`/`test_tool_executor.py` from the structure; write a new ADR for the agent-owned `/api/mcp` actuation boundary (replacing the superseded ADR-005); document crew-aware discovery + `agent_label`.

**Priority:** P3
**Effort:** S

Remove the tool-execution objective + deleted test files; add the 9 newer test files + 4 new modules to the module table; document the test approach for usage/doctor/memory/diagnostics/contract.
