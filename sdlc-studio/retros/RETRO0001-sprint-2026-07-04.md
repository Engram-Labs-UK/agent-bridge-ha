## Lessons

1. **A deterministic gate must be validated against its own template.** `audit.py check` flags every bug authored from the skill's own `templates/core/bug.md` as "underspecified" — the check requires `## Steps to Reproduce`/`## Proposed Fix` but the template says `## Reproduction Steps`/`## Fix Description`. Ruled false positive in the ledger; **raise upstream against the sdlc-studio skill** (LL0008 class: a tool that mis-reports readiness).
2. **Feature-pair blind spots hide where contracts compose.** US0033 (streaming) and US0036 (confirm markers) each shipped tested, but no test exercised them together — that intersection was BG0012. When a new output path parallels an existing content contract, add the interaction case at ship time.
3. **`entry.data` writes during setup vs `add_update_listener` ordering is a reload-loop hazard class.** Persisting the webhook id had to move before the listener registration. Rule: register update listeners after all setup-time entry writes.
4. **A cheap property probe (random chunkings vs a single-shot oracle) is the right depth for stream-parser code.** The critic's ~4,000-chunking probe over `_to_delta_stream` vs `_parse_confirm_marker` cost minutes and would have caught any boundary bug; reuse for future incremental parsers.
